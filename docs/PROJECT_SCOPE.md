# AL-FALLAH Project Scope

AL-FALLAH is intended to become an autonomous mobile-manipulation platform for tree and vegetation maintenance.

The project is not limited to geometric tree shaping. Geometric shaping is currently used as a convenient first manipulation problem because it provides a clear target geometry, measurable trimming regions, and a repeatable simulation workflow.

Potential project capabilities include:

- geometric canopy shaping;
- selective branch pruning;
- tree/vegetation inspection;
- perception-driven cutting decisions;
- autonomous mobile-base repositioning around vegetation;
- multi-view canopy reconstruction;
- reachability-aware manipulation;
- scan-plan-act-verify closed-loop operation.

## Development stages

The repository distinguishes between three kinds of work:

1. **Simulation demos** — focused proofs of concept that deliberately simplify the overall problem.
2. **Experiments** — temporary research code, parameter studies, unsuccessful approaches, and technical investigations.
3. **Physical-system development** — software, mechanical design, and electrical design intended for the physical AL-FALLAH platform.

A demo is not automatically promoted into the physical-system implementation. Algorithms and hardware concepts may be rewritten, reorganized, or replaced as perception, hardware, safety, timing, calibration, manufacturing, and deployment constraints are introduced.
