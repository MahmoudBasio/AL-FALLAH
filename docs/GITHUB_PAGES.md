# Interactive viewer on GitHub Pages

The root `index.html` opens the embedded plant viewer already stored in the
repository. `.nojekyll` tells GitHub to serve these static files directly.

Enable the site once in repository Settings → Pages:

1. Source: **Deploy from a branch**.
2. Branch: **main**.
3. Folder: **/ (root)**.
4. Click **Save** and wait for the Pages deployment to finish.

The expected project URL is https://MahmoudBasio.github.io/AL-FALLAH/ .
It is only available after Pages has been enabled and deployment succeeds.
No custom domain, package installation or API key is required.

Future pushes to `main` update the site. The README remains a static GitHub
document; its viewer link opens the interactive site separately.
