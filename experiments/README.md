# Experiments

This directory is for temporary research work that should not be confused with either polished simulation demos or physical-system development.

Examples include parameter sweeps, reachability tests, alternative path planners, discarded approaches, perception prototypes, and quick validation scripts.

Promising work can later be rewritten or promoted into a dedicated demo or into the physical-system implementation after validation.

- [Kinect plant reconstruction](kinect_plant_reconstruction/): manual capture,
  offline alignment and fusion of 38 views, a saved plant cloud and RViz viewer.
