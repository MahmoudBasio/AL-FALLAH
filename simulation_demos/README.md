# Simulation Demos

This directory contains focused AL-FALLAH simulation demonstrations.

Each demo is a proof of concept for a limited technical question. A demo may intentionally use synthetic data, simplified geometry, simulator-only logic, or a third-party robot model. It should not be interpreted as the final AL-FALLAH simulation or software intended for deployment on the physical AL-FALLAH platform.

## Demos

### Demo 01 — Geometric Canopy Shaping with TIAGo

Validates synthetic foliage generation, user-defined target geometry, excess-foliage classification, raster trimming-path generation, MoveIt Cartesian execution, and virtual trimming with a stationary base.

Future demos will be added as independent folders so that the progression of the project remains clear.
